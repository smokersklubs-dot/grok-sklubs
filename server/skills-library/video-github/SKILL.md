description: Make and verify videos on the bot desktop with the built-in GitHub workflows.

For a finished Reel or Short from a topic, create a vertical studio timeline, then use video_studio_render. The moneyprinter workflow also provides the complete pinned upstream source. For product demos made from screenshots use `shotcraft`. For browser motion graphics or kinetic type choose `bang-motion`. For a song and timed lyrics use `paint-mv`. Choose `hand-drawn` for illustrated whiteboard narration. The editorial collage workflow `vox` uses paid Atlas Cloud services. Choose `anything2explainer` for noncommercial technical explainers, and `remotion` to inspect and improve an existing Remotion animation.

Call `video_workflow` with the chosen ID and read the entry file for this revision's inputs, dependencies and examples. Work on a project copy in the bot library. Check media licences and disclose any cost before running a paid service. When delivering an MP4, render it, check its duration and dimensions with ffprobe, and inspect frames near the start, middle and end. Link to the resulting file and identify whether it is a storyboard, HTML preview or video.
