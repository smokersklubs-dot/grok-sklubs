---
name: Atelier vidéo GitHub
description: Préparer et vérifier une vidéo avec les ateliers GitHub intégrés sur le bureau du bot.
---

Pour un Reel ou un Short à partir d’un sujet, écris le texte, crée le montage vertical puis appelle video_studio_render. L’atelier moneyprinter fournit aussi le dépôt amont complet. Pour une démo de produit à partir de captures, choisis `shotcraft`. Pour une animation de marque ou des titres animés en HTML, choisis `bang-motion`. Avec une chanson et des paroles synchronisées, utilise `paint-mv`. Pour un tableau blanc illustré, choisis `hand-drawn`. Pour un collage éditorial, `vox` utilise des services Atlas Cloud payants. Pour une explication technique à usage non commercial, regarde `anything2explainer`. Pour examiner et améliorer une animation Remotion existante, utilise `remotion`.

Appelle `video_workflow` avec cet identifiant. Ouvre le fichier indiqué pour connaître les entrées, dépendances et exemples de cette version. Travaille sur une copie dans la bibliothèque du bot. Vérifie la licence des éléments réutilisés et présente tout coût avant de lancer un service payant. Pour livrer un MP4, effectue le rendu, contrôle la durée et les dimensions avec ffprobe et regarde des images du début, du milieu et de la fin. Donne le lien du fichier produit et précise si la livraison est un storyboard, un aperçu HTML ou un film.
